深圳大学 UOOC 慕课讨论助手 v1.1.0

用于深圳大学 UOOC 慕课刷讨论次数：自动填写并点击“发布回复”。
支持 Chrome / Edge，无需安装 Node.js。

安装
1. 解压安装包。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择 extension 文件夹，里面应直接包含 manifest.json。

使用
1. 登录 UOOC，打开自己的课程讨论帖子。
2. 打开“UOOC 讨论回复助手”，填写自己的回复内容。
3. 设置间隔：30～86400 秒的整数，默认 70 秒。
4. 设置次数：1 表示只发一条，0 表示持续运行。
5. 点“检测页面”，再点“开始后台回复”，授权当前课程网站。

启动立即发送首条，UEditor 会预留约 1 秒同步数据。
之后按设定间隔执行，倒计时进度条显示等待进度。
首次测试可将上限设为 1，再到帖子核对实际回复。

可以关闭面板或切换标签页；保留课程标签页、保持浏览器运行、账号登录、
电脑唤醒联网。再次打开面板可停止任务。
修改参数时先停止，再修改并开始。重新开始会立即发第一条。

升级：停止任务，覆盖原 extension 文件夹，在扩展管理页点“重新加载”，
再回到帖子重新检测。上次失败的草稿需先手动清空。

找不到按钮时，高级设置的按钮 CSS 选择器填写 .release[ng-click]。
