# 深圳大学 UOOC 慕课讨论助手

用于**深圳大学 UOOC 慕课刷讨论次数**的 Chrome / Edge 小插件。在课程讨论帖下自动填写回复并点击「发布回复」，支持自定义等待间隔、次数上限和后台运行。

当前版本 **1.1.0**。启动时立即发送第一条，后续按设置的间隔执行。扩展无需服务器、Node.js 或命令行，下载后直接加载即可。

![倒计时与运行进度](docs/images/popup-running.png)

截图全部来自本地匿名演示：姓名、课程、帖子和回复均为占位信息，不包含真实学生姓名、学号或讨论记录。本项目为同学自用分享，并非学校或 UOOC 官方项目。

## 快速安装

1. 下载安装 ZIP 并解压；也可以用 GitHub「Code → Download ZIP」下载整个项目后解压。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择 **extension 文件夹**，该文件夹内应有 `manifest.json`。
4. 登录自己的 UOOC 账号，进入课程的「课程讨论 → 综合讨论 → 帖子详情」页面。
5. 打开「UOOC 讨论回复助手」，填写自己的回复，设置间隔和次数上限。
6. 点击「检测页面」，确认识别成功后点击「开始后台回复」，允许扩展访问当前课程网站。

第一次建议把次数上限设为 **1**：启动后立即发送一条并停止，便于核对结果。UEditor 会预留约 1 秒同步内容。

详细步骤见 **[配图使用教程](docs/USAGE.md)**；准备上传自己的仓库，见 **[GitHub 分享指南](docs/GITHUB.md)**。

## 功能与设置

| 设置或功能 | 说明 |
| --- | --- |
| 回复内容 | 自行填写，1～2000 个字符；课程页面可能另有字数要求 |
| 回复间隔 | **30～86400 秒**的整数，默认 **70 秒** |
| 次数上限 | `0` 持续运行，`1` 只发一条；包含启动时的第一条 |
| 倒计时进度条 | 展示本轮等待进度，重新打开面板可恢复剩余时间 |
| 开始与停止 | 启动时立即发送；停止取消后续任务 |
| 后台运行 | 面板关闭、切换标签页或最小化后仍由后台调度 |
| 高级设置 | 可填写输入框和发布按钮的 CSS 选择器 |
| 运行记录 | 保存最近 20 条记录，便于排查问题 |

修改运行中的间隔或内容时，先停止，修改后再开始；重新开始会立即发送第一条。30 秒下限来自浏览器后台定时 API，系统调度可能让实际等待延长。[Chrome Alarms API 说明](https://developer.chrome.com/docs/extensions/reference/api/alarms)

## 适配范围和运行条件

已针对提供的 UOOC `div.release[ng-click]` 发布按钮和 **UEditor + AngularJS** 编辑器结构做适配：写入编辑器、通知内容和字数变化、同步表单，再校验后点击。也保留普通文本框、`contenteditable` 和同源 iframe 的识别。

目前通过了本地模拟页面、真实 AngularJS 数据绑定和浏览器后台运行验证，尚未登录真实课程逐一验证各页面版本。课程页面或平台改版可能需要调整选择器。面板「已点击」表示触发按钮的次数，实际回复及讨论次数以课程页面为准。

- 保持浏览器运行、课程标签页打开、账号登录、电脑唤醒联网。
- 可在浏览器性能设置中，将课程网站加入「始终保持活动」或 Edge 的「从不将这些网站置于睡眠状态」名单。
- 页面跳转、标签页关闭或被冻结时停止；浏览器重启后需重新开始。
- 不覆盖已有草稿；提交后 8 秒内未检测到输入框清空时暂停，不自动重复提交。

识别失败、字数错误等问题见 [使用教程中的排查部分](docs/USAGE.md#常见问题)。

## 更新旧版

停止任务，用新版 `extension` 文件夹覆盖原文件夹，在扩展管理页点击本扩展的「重新加载」（圆形箭头），然后回到帖子重新检测。原有本地设置保留；旧版没有间隔设置时默认使用 70 秒。

如果一直加载的是本项目的 `extension` 文件夹，更新代码后直接重新加载即可。

## 开发与本地验证

扩展无运行时依赖。Node.js 20+ 仅供修改代码、生成截图和测试：

```powershell
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

单元测试覆盖立即发送、自定义间隔、重复调度、停止、恢复和进度计算。浏览器测试覆盖编辑器接口、真实 AngularJS 表单同步、自定义 30 秒实际后台任务和面板交互。

测试使用独立临时浏览器配置和本地页面，并生成 `docs/images/` 中的匿名截图。AngularJS 仅用于测试旧页面的数据绑定，开发依赖不会打包进扩展。

手动演示：在项目根目录运行 `python -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765/demo/`。结束后 Ctrl+C 关闭服务器。演示仅在本地显示回复。

## 打包与分享

Windows 下在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package.ps1
```

`dist/` 会生成两个包：安装包包含扩展和配图教程，可直接发给同学；源码分享包另含测试、演示和打包脚本，适合上传 GitHub。

打包采用白名单，排除依赖、测试输出、旧 ZIP、浏览器配置和原始截图，`.gitignore` 也已忽略本地生成物。

```text
extension/          可直接加载的扩展
docs/USAGE.md       配图使用教程
docs/GITHUB.md      GitHub 上传与分享指南
docs/images/        匿名演示截图
demo/               本地模拟课程讨论
tests/              单元测试、浏览器验证
scripts/package.ps1 安装包与源码包打包脚本
CHANGELOG.md        更新记录
安装说明.txt        简明安装说明
```

## 隐私与数据

内容、设置和运行记录保存在本机。扩展没有统计服务或第三方上传接口，只在授权的课程页面填写和点击；课程页面自身会向其服务器提交回复。公开示例均已匿名，原始含姓名的截图未纳入仓库或分享包。

权限为 `activeTab`、`scripting`、`alarms`、`storage`，仅在开始时申请当前网站访问权限。反馈时提供浏览器版本、插件版本、提示文字及相关元素结构即可。

编辑器参考：[UEditor 官方源码](https://github.com/fex-team/ueditor/blob/master/_src/core/Editor.js)、[AngularJS NgModelController](https://code.angularjs.org/1.8.2/docs/api/ng/type/ngModel.NgModelController)。版本变化见 [CHANGELOG](CHANGELOG.md)。
